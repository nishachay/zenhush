Written offer of corresponding source code
==========================================

This offer accompanies the dither test build and satisfies the
corresponding-source obligations of GNU LGPL v3 (Qt 6.12.0, via GPL v3
section 6) and GNU LGPL v2.1 (FFmpeg 9.0.1, section 6).

The dither project offers to provide, to anyone who possesses this
binary, a complete machine-readable copy of the corresponding source
code for the LGPL-licensed libraries bundled in it, on request, for a
charge no more than the reasonable cost of delivering it. This offer is
valid for at least three years from 12 November 2026 (until at least
12 November 2029).

To request source, open an issue or contact the maintainer through the
dither project repository.

For convenience, the exact corresponding source is also publicly
available from the upstream projects (all URLs verified live on
12 November 2026):

- Qt 6.12.0:
  https://download.qt.io/official_releases/qt/6.12/6.12.0/single/qt-everywhere-src-6.12.0.tar.xz
  (the bundled libraries come from the official PySide6 6.12.0 wheels,
  built from this Qt release; PySide6 source:
  https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.12.0-src/pyside-setup-everywhere-src-6.12.0.zip)
- FFmpeg 9.0.1 (bundled by Qt Multimedia):
  https://ffmpeg.org/releases/ffmpeg-9.0.1.tar.xz
- Python 3.10.12 runtime (PSF license; source not required but listed):
  https://www.python.org/ftp/python/3.10.12/Python-3.10.12.tgz
- PyInstaller 6.22.3 bootloader:
  https://github.com/pyinstaller/pyinstaller/archive/refs/tags/v6.22.3.tar.gz

dither's own source code is included in this package under source/.
