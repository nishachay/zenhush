Zenhush - Linux test build (private, not for public distribution)

What this is
  Zenhush - noise for focus and rest. A tiny noise machine for your
  top bar. Tray icon + popup with
  5 synthesized sounds (brown, white, pink, rain, ocean), volume, sleep
  timer, restart. One-directory build, nothing to install.

Tested environment (what this build was actually verified on)
  - Ubuntu 22.04.5 LTS, x86_64, glibc 2.35
  - X11 session (Xvfb), PulseAudio (null sink), Ayatana
    indicator-application StatusNotifier watcher
  - Verified there: window renders, click plays, PCM audio captured from
    the sound server across a loop seam, tray show/hide/quit through a
    real D-Bus watcher, <1% of one CPU core, ~90 MB RAM.

Estimated compatibility (NOT tested)
  - Other x86_64 Linux desktops with glibc >= 2.35 (the build machine's
    glibc) should work; older glibc will refuse to start the binary.
  - Other distributions, Wayland sessions, and other tray hosts are
    untested. If no tray host exists the app falls back to a small window.
  - Windows and macOS builds do not exist yet.

Runtime dependencies
  - Required on X11: libxcb-cursor0
      sudo apt install libxcb-cursor0
    Without it the binary aborts at startup with Qt's error
    "xcb-cursor0 or libxcb-cursor0 is needed" (verified both ways).
  - Audio output: PulseAudio or PipeWire (pulse API).

Run
  chmod +x zenhush/zenhush
  ./zenhush/zenhush
  Click the tray icon (or use the fallback window) and pick a sound.
  The zenhush/ directory must stay together: zenhush/zenhush loads its
  bundled libraries from zenhush/_internal/.
